| 항목 | 내용 |
|---|---|
| 프로젝트 | 해외 연사 초청자 관리 솔루션 |
| 구성 | 관리 대시보드 (내부 전용 · 비배포) |
| 작성 내용 | 기능 명세 / 화면 정의 |
| 버전 | v1.0 |
| 기준 행사 | 제12회 국제 스마트시티·AI 컨퍼런스 (데모 데이터) |

## 1. 업무 프로세스에 따른 기능 도출

기존 골격(초기 세팅 / 초청·참가자 관리 / 진행 사항 관리 / 변경 이력)을 유지하면서,
**국제행사 해외 연사 초청 시 실제로 발생하는 부가 업무**(출입국·사증, 세무·해외송금, 의전,
콘텐츠·저작권 동의, 현장 운영, 사후 정산)를 추가 도출하여 8단계로 재정의하였다.

| 단계 | 핵심 업무 | 대응 화면 |
|---|---|---|
| ① 기획·세팅 | 행사 기본정보, 등급별 지원 패키지, 체크리스트 템플릿, 권한 설계 | 행사 설정·템플릿 |
| ② 발굴·선정 | 롱리스트, 이해충돌·중복 초청 확인, 선정위 승인, 다양성 균형 | 초청 파이프라인 |
| ③ 초청·계약 | 사전 타진 → 공식 초청장 → 수락 → Speaker Agreement 서명 | 초청 파이프라인 / 연사 상세 |
| ④ 출입국·비자 | 사증 종류 판정, 사증발급인정서(CCVI), K-ETA, 여권 유효기간 | 출입국·비자 |
| ⑤ 여행·의전 | 항공 발권, 숙박(루밍리스트), 픽업·샌딩 배차, 식이·접근성 | 여행·의전 |
| ⑥ 콘텐츠·발표 | 약력·사진·초록·발표자료, 녹화·중계/개인정보 동의, 통역 | 제출물·콘텐츠 / 세션·프로그램 |
| ⑦ 현장운영 | 런시트, 체크인 상태, 배지·기념품, 리허설, 비상 연락망 | 현장 운영 |
| ⑧ 정산·사후 | 강연료·원천징수·조세조약, 실비 정산, 해외송금, 감사서한 | 정산·예산 |

전 단계 공통: **리스크 D-day 역산 경보 · 변경 이력(감사 로그) · 권한별 데이터 공유 · Excel 내보내기**

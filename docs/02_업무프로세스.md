# 해외 연사 초청 업무 프로세스 (8단계)

행사 시작일을 **D-day** 로 두고 전 업무를 역산한다. 아래 D-offset은 국제행사 실무에서 통용되는
일반적 기준을 데모 템플릿으로 정리한 값이며, 행사 규모·국가 구성에 따라 설정에서 조정한다.

## Pain Point → 해결 방식 매핑

| Pain Point (기존 엑셀 운영) | 이 솔루션의 해결 방식 | 구현 위치 |
|---|---|---|
| 초청 업무에서 소통해야 하는 이해관계자가 많고 다양하다 | 역할(사무국/PCO/리에종/여행사/재무)별 데이터 범위 정의, 연사마다 **담당 리에종 + Principal(책임자)** 명시 | 설정·권한, 초청자 워크스페이스 |
| 정보 유입이 많고 변경이 잦다 | 항목 단위 상태값(예약·제출물·비자·프로그램)과 **변경 이력 자동 기록**, 회신 기한 팔로업 | 변경 이력, 커뮤니케이션 |
| 초청 담당자에게 모든 업무·소통이 집중되어 지체된다 | 체크리스트 템플릿으로 업무를 **역할별로 자동 분배**, D-day 역산 경보로 우선순위 제시 | 업무·체크리스트, 리스크·경보 |
| 엑셀로 주고받는 데이터의 오염과 휴먼 에러 | 값 교차 검증(**데이터 정합성 엔진 13종**) + 코드화된 상태값 + Excel 내보내기 표준화 | 워크스페이스, 리스크·경보 |

## 전체 흐름

```
① 기획·세팅 ─ ② 발굴·선정 ─ ③ 초청·계약 ─┬─ ④ 출입국·비자 ─┐
                                        ├─ ⑤ 여행·의전 ───┼─ ⑦ 현장운영 ─ ⑧ 정산·사후
                                        └─ ⑥ 콘텐츠·발표 ─┘
```
④~⑥은 수락(계약) 이후 **병렬**로 진행되며, 셋 중 하나라도 지연되면 현장 운영이 영향을 받는다.
따라서 대시보드는 세 축(비자 / 발권 / 제출물)을 각각 독립 지표로 노출한다.

## 단계별 상세

### ① 기획·세팅 (D-200 ~ D-180)
- 초청 예산 수립 및 집행 승인 (연사 1인당 단가 = 강연료 + 항공 + 숙박 + 지상교통 + 일비)
- 등급 체계(Keynote / Invited / Panel / Moderator / Workshop) 및 **등급별 지원 패키지** 확정
- 체크리스트 템플릿, 메일 템플릿, 권한(사무국/PCO/리에종/여행사/재무) 설계
- 개인정보 수집 항목·보유기간·동의 문안 확정 (EEA 연사 대상 GDPR 고지 포함)

### ② 발굴·선정 (D-185 ~ D-165)
- 롱리스트 작성(추천 경로, 과거 참여 이력, 전문 분야, 기관·지역·성별 균형)
- 이해충돌·중복 초청·경쟁 행사 일정 충돌 확인
- 선정위원회 심의 → 등급·세션·예산 배정 → **대체 후보(Backup) 풀** 별도 확보

### ③ 초청·계약 (D-160 ~ D-110)
- 사전 타진(Save-the-date) → 공식 초청장(Invitation Letter) → 수락 회신(기한 관리)
- 조건 합의: 강연료(세전/세후 명시), 항공 클래스, 숙박 박수, 동반자 지원 범위
- **Speaker Agreement** 서명: 발표 주제·시간, 녹화/중계·자료 활용 범위, 취소 조항
- 거절 시 즉시 대체 후보 투입, 거절 사유를 차기 행사 후보풀에 기록

### ④ 출입국·비자 (D-100 ~ D-30)
| 구분 | 내용 |
|---|---|
| 판정 | 국적별 사증 면제 여부, K-ETA 대상 여부, **강연료 수령 시 체류자격(C-4 단기취업) 검토** |
| 서류 수취 | 여권 사본(잔여 유효기간 6개월 이상), 재직증명서, 사진 |
| 주최 발급 | 초청장, 초청사유서, 신원보증서, 사업자등록증, 행사 프로그램(영문) |
| 사증발급인정서(CCVI) | 주최기관이 출입국·외국인청에 신청 → 발급 후 현지 공관에서 사증 발급 (심사 약 2~3주) |
| 모니터링 | 공관 예약 → 접수 → (인터뷰) → 발급/거절. 거절 시 재신청 또는 온라인 전환 |
| 백업 | D-30 시점에 사증 미발급 건은 **온라인 발표 전환 여부 결정** |

### ⑤ 여행·의전 (D-70 ~ D-1)
- 항공: 선호 정보 수집(항공사·마일리지·좌석·수하물·식사) → 스케줄 확정 → **D-60 발권**(요금 보장)
- 숙박: 객실 블록 확보(D-55), 정산 방식(주최 일괄 Master Bill / 본인 결제 후 정산) 명확화
- 지상: 공항 픽업·샌딩 배차(D-10), 미팅포인트·피켓·기사 연락처, 의전 차량, 전담 리에종 배정
- 개인 요구: 식이(할랄·채식·알러지), 접근성(휠체어·무대 램프), 종교, 동반자
- 여행자보험 가입 및 증서 송부, 개인 일정표(Itinerary) 발송(D-7)

### ⑥ 콘텐츠·발표 (D-70 ~ D-14)
- 약력·사진·CV·초록 수집(D-60, 프로그램북 조판 D-25 역산)
- 녹화·중계 동의, 개인정보 처리 동의(GDPR), 자료 공개 범위 확인
- 발표자료 수취·기술 검수(D-14): 비율·폰트·영상 코덱·해상도, 온라인 연사 회선 점검
- 동시통역사 배정 및 자료 사전 전달(D-20), 필요 시 자료 번역

### ⑦ 현장운영 (D-1 ~ D+0)
- 테크 리허설(시차 고려), 스피커 레디룸·VIP 라운지, 배지·기념품
- 실시간 상태 공유: 공항 도착 → 호텔 체크인 → 현장 체크인 → 발표 완료 → 출국
- 갈라디너 좌석 배치(의전 서열), 비상 대응(항공 결항·건강 이상·자료 사고)

### ⑧ 정산·사후 (D+7 ~ D+35)
- 강연료 지급: 원천징수(기본 22%) 또는 조세조약 제한세율(거주자증명서·신청서 수령 시)
- 실비 정산: 증빙(영수증 원본·카드 전표), 선지급/후정산 구분
- 해외 송금: 수취인 영문명 = 여권 영문명 일치 확인, SWIFT/IBAN, 수수료 부담 주체
- 원천징수이행상황 신고·지급명세서 제출(지급월 다음 달 10일)
- 감사 서한·만족도 설문, 발표자료·영상 아카이브(동의 범위 내), 차기 후보풀 이관

## RACI (역할별 책임)

| 업무 | 사무국 | PCO | 리에종 | 여행사 | 재무 |
|---|---|---|---|---|---|
| 연사 선정·초청장 | **R/A** | C | I | - | I |
| 계약·강연료 합의 | **R/A** | I | C | - | C |
| 비자 서류·인정서 | **A** | I | **R** | - | - |
| 항공·숙박 | C | C | I | **R** | I |
| 배차·의전 | I | **R** | C | C | - |
| 제출물 수집·검수 | C | **R** | C | - | - |
| 현장 운영 | A | **R** | R | - | - |
| 정산·원천징수 | A | I | I | C | **R** |

R = 실행, A = 최종 책임, C = 협의, I = 공유

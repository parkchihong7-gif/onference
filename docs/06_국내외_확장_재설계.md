# v2.0 — 국내외 컨퍼런스 행사 관리로의 확장

기존 범위(국제 컨퍼런스 해외 연사 초청 관리)를 **국내외 컨퍼런스 행사 관리**로 넓히면서
설계를 다시 정리한 결과다.

---

## 1. 핵심 재설계 — 축을 둘로 분리

기존에는 "국제 행사 = 해외 연사"가 한 덩어리였다. 이것이 국내 학회를 담을 수 없는 원인이었으므로
축을 둘로 나눴다.

| 축 | 값 | 결정하는 것 |
|---|---|---|
| **행사 축** `Conference.scope` | 국내 / 국제 | 메뉴 구성, 화면 용어(연자↔연사), 기본 활성 모듈 |
| **참가자 축** `Speaker.residency` | 국내 / 해외 | 출입국·사증, 해외송금·조세조약, 국제선 적용 여부 |

그 결과:

- **국내 학회에 해외 연자 2명**이 있어도 — 그 2명에게만 사증·해외송금이 붙고, 섭외·계약·교통·숙박·제출물·현장·정산은 국내 연자와 **같은 모듈**로 돈다.
- **국제 컨퍼런스의 국내 좌장**도 같은 원리로 처리된다.
- 국제 행사라도 **국내에서 진행되는 중간 과정**(호텔, 지상 교통, 현장 운영, 사례비 지급)은 국내 행사와 동일한 화면·동일한 로직을 쓴다.

```
공통 경로(모든 연자)   섭외 → 계약 → 교통·숙박 → 제출물 → 현장 → 정산
                                  │
해외 연자만 추가        └─→ 출입국·사증 · 해외송금/조세조약 · 공항 의전
국내 학회만 추가        └─→ 연수평점 · 초록심사 · 참가등록 · 후원/전시
```

## 2. 모듈 체계

행사마다 활성 모듈을 켜고 끈다(행사 설정 · 모듈). 메뉴는 활성 모듈만 노출한다.

| 구분 | 모듈 |
|---|---|
| 공통 | 초청·연자 · 세션·프로그램 · 제출물·콘텐츠 · 교통·숙박 · 현장운영 · 정산·예산 · 문서·회의록 · 캘린더 |
| 국내 학회 | **연수평점 · 초록심사 · 참가등록 · 후원·전시** |
| 해외 연자 (검증 전) | **출입국·사증 · 해외송금·조세조약 · 의전** |

해외 전용 모듈은 **해외 연자가 실제로 있을 때만** 메뉴에 나타나며, 메뉴와 화면 상단에
`검증 전(Hold)` 표시를 달았다. 실제 신청 사례로 검증·테스트되지 않았음을 화면에서 명시한다.

## 3. 국내 학회 모듈 (예시 업종: 병원 학회)

데모 행사: **제38차 한국임상내과연구학회 추계학술대회** (가상 학회·가상 인물·가상 병원, 개막 D-24)
연자 14명(국내 12 / 해외 2), 참가 등록 148명, 초록 26편, 후원 8개사.

| 모듈 | 다루는 것 |
|---|---|
| **연수평점** | 인정 기관별 신청·승인 평점, 평점 인정 세션, 부여 조건(출석 QR), 이수자 명단 제출, **면허번호 누락자 탐지** |
| **초록 심사** | 투고·심사 점수·채택/반려, 구연/포스터 배정, 우수초록 후보, 트랙별 분포 |
| **참가 등록** | 사전/현장 등록, 구분별 등록비(정회원·전공의·학생·비회원), 수납·미납, 식권, 현장 체크인 |
| **후원·전시** | 등급별 후원 계약·입금, 부스 배정, 제공 항목(심포지엄·광고·부스) 이행 관리 |

국내 실무에 맞춘 변경:

- **교통**: 국제선·국내선·KTX·고속버스·자가용을 **하나의 이동 레코드**로 통합(`TravelMode`). KTX 좌석·열차번호도 같은 구조에 담긴다.
- **사례비 세무**: 사업소득 3.3% / 기타소득 8.8% / 비거주자 22% / 조세조약 제한세율을 `TaxType`으로 구분해 집계.
- **제출물**: 강의계획서, **이해관계 선언(COI)**, 사례비 지급정보(통장·신분증) 등 의료 학회 필수 서류 추가.
- **판정 규칙**: 수도권 당일 참석 연자에게 숙박·항공 경고가 뜨지 않도록, 리스크·정합성 규칙을 "원거리 이동이 있는 연자"로 한정.

## 4. 노션에서 하던 기능의 프로그램 내 구현

| 노션 기능 | 이 대시보드의 구현 |
|---|---|
| 페이지·문서 작성 | **문서·회의록** 모듈 — 마크다운 편집/보기, 템플릿 4종, 고정(핀), 태그, 연결 레코드 |
| 데이터베이스 뷰 | 테이블·칸반(파이프라인/비자)·**캘린더**·간트·매트릭스 — 같은 데이터의 다른 뷰 |
| 코멘트·멘션 | **코멘트 스레드** — 연자·문서·초록·후원·세션에 달리며 @멘션과 해결 처리 지원 |
| 전역 검색 | **Ctrl/⌘+K 통합 검색** — 연자·문서·세션·업무·초록·등록·후원·코멘트를 한 번에 |
| 템플릿 | 문서 템플릿 + 체크리스트 템플릿(국내 학회판 23항목 신설) + 메일 템플릿 |
| 작업 배분 | 회의록의 **액션 아이템 표를 업무로 즉시 등록**(담당·기한 자동 매핑) |
| 파일 첨부 | 첨부 대장(파일명·보관 위치·기밀 여부) — 실물은 문서고/드라이브에 두고 위치와 권한만 관리 |
| 변경 이력 | 전 엔터티 감사 로그(행사 범위 필터 포함) |

노션 대비 이 대시보드가 갖는 차이는 **규칙이 항상 돈다는 점**이다. 리스크 D-day 역산과 정합성 13종 검증은
사람이 요청하지 않아도 매 화면에서 자동 판정된다.

## 5. 데모 날짜 기준 변경

기존 시드는 절대 날짜(2026-11-18 등)로 고정되어 있어 시간이 지나면 상황이 어긋났다.
**모든 행사 일정을 오늘 기준 상대 날짜로 전환**했다.

- 국제 컨퍼런스: 오늘 + 63일 (사증·발권 리드타임 데모에 적합)
- 국내 학회: 오늘 + 24일 (사전등록·평점·현장 준비 단계)
- 종료 행사: 오늘 − 126일

언제 열어도 같은 상황이 재현된다.

## 6. 이번 작업에서 수정한 오류

| 증상 | 조치 |
|---|---|
| 순환 import(seed ↔ seedDomestic)로 앱 전체가 흰 화면 | 공용 유틸을 `data/base.ts`로 분리 |
| 수도권 당일 참석 연자에게 숙박·항공 미확정 경고 | 원거리 이동(국제선/국내선/KTX/버스) 연자로 한정 |
| 교통 확정률 분모에 자력 이동 연자가 포함 | 예약이 필요한 연자만 분모로 집계 |
| 사증 대상이 0명인데 사증 카드가 0/0으로 노출 | 실제 사증 대상이 있을 때만 표시, 없으면 등록·제출물 카드로 대체 |
| 마일스톤이 날짜순으로 정렬되지 않음 | 날짜 정렬 적용 |
| 국내 연자 이름이 영문으로 표시 | `displayName()` 도입(한글명 우선) |
| 참가 등록일이 미래로 생성 | 오늘 이전으로 생성 범위 제한 |
| 학생·스태프의 면허번호가 "누락"으로 표시 | 평점 비대상은 '해당없음'으로 구분 |

## 7. 남은 작업 (요청 시 진행)

- **노션 커넥트 연동** — 입력은 노션, 판정은 대시보드. 노션 API는 브라우저에서 직접 호출할 수 없으므로
  `npm run sync:notion` 으로 노션 DB를 읽어 시드를 갱신하고 단일 HTML을 재생성하는 방식을 제안한다(파일 하나 성격 유지).
- **큐시트(Run of Show) 시간 재계산** — 세션 시간 변경 시 이후 전 세션을 자동으로 밀고 점심·종료 초과를 경고.
- 해외 연자 모듈의 실제 검증(사증 신청 1건 기준 테스트) 후 Hold 해제.

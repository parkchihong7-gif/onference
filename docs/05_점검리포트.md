# 전체 프로세스 재검토 리포트 (v1.1)

초안(v1.0) 전 화면·로직을 다시 검토하여 **발견한 오류**, **수정 내역**, **보강 항목**을 정리한다.
검토 기준: 도메인 로직(리스크·집계) → 데이터 정합성 → 화면 동작 → 빈 상태/경계값.

---

## 1. 발견·수정한 오류

| # | 위치 | 증상 | 원인 | 조치 |
|---|---|---|---|---|
| 1 | 초청 파이프라인 | 회신 기한 경과 배지가 실제와 다르게 표시 | 기준일을 `speakers[0].updatedAt`(임의 연사의 수정일)로 비교 | `today()` 기준으로 변경 |
| 2 | 연사 상세 · 여권 | 여권 유효기간 판정이 특정 날짜 문자열에 고정 | `'2027-05-20'` 하드코딩 | 행사 **종료일 + 180일** 기준으로 계산 |
| 3 | 대시보드 · 체류 간트 | 월 길이에 따라 축이 잘리거나 남음 | 축 범위를 `YYYY-MM-01 ~ YYYY-MM-30` 문자열로 생성 | 실제 최초 입국 ~ 최종 출국 기준으로 산출 |
| 4 | 대시보드 · 퍼널 | 거절 연사가 "공식초청" 누적에서 빠져 수락률과 어긋남 | 거절·취소 단계의 인덱스가 -1 | 거절·취소는 **공식초청까지 도달**한 것으로 집계 |
| 5 | 리스크 엔진 | 초청 수락 전 연사에게 제출물 지연 경보가 발생 | 제출물 요청 전 상태를 지연으로 판정 | **확정(수락·계약완료) 연사**만 검사 |
| 6 | 비자 리드타임 | 화면과 엔진이 각각 계산(중복 정의) | 동일 수식을 두 곳에 작성 | `visaLeadDays()` / `visaSlack()` 로 일원화 |
| 7 | 비자 위험도 | 여유 1일 건이 "주의"로만 표시 | 임계값이 `필요일 × 0.6` | **여유 7일 미만 = 즉시 조치 / 21일 미만 = 주의** 로 재정의 |
| 8 | 상태 저장 | 업무 일자가 실제 시각으로 기록되어 데모 기준일과 어긋남 | 리듀서에서 `new Date()` 사용 | 감사 로그는 실제 시각, **업무 일자는 기준일**로 분리 |
| 9 | 체류·숙박 데이터 | 출국일과 체크아웃 일자가 어긋남(패키지 박수 고정) | 숙박 박수를 등급 패키지 값으로 고정 | **배정 세션 일정에서 체류 기간 역산**, 지원 한도는 별도 보관 |
| 10 | 여권번호 표기 | `영893****` 처럼 한글 국가명이 접두어로 표시 | 국가명 첫 글자를 사용 | 국가 코드(GB/FR/SG…) 매핑 적용 |
| 11 | 대시보드 · 변경 이력 | 다른 행사를 선택해도 이력이 그대로 표시 | 감사 로그에 행사 구분이 없음 | 엔터티 소속으로 **현재 행사 범위 판별**(`auditOf`), 이력 화면에 토글 추가 |
| 12 | 예산 구성 그래프 | 범례에 `강연료 3,970만 39700000` 처럼 원시값 중복 출력 | 라벨에 금액을 넣은 채 값도 출력 | 값 포맷터(`valueFormat`) 분리 |
| 13 | 빈 상태 | 연사가 없는 행사 선택 시 빈 카드만 표시 | 빈 배열 처리 누락 | 국가 분포·준비도·이력 카드에 안내 문구 추가 |
| 14 | 제출물 매트릭스 | 세로 헤더 라벨이 잘림 | 긴 원본 라벨을 그대로 출력 | 축약 라벨 + 원문 툴팁 |
| 15 | 여행 · 항공 | 편명이 `ET ET801` 로 중복 표기 | 항공사 코드 + 편명 동시 출력 | 편명만 표기 |

## 2. 보강 항목 (레퍼런스 이미지 반영)

### 2.1 초청자 워크스페이스 (신규 화면)
좌측 초청자 카드 리스트 + 우측 상세(Personal / Booking / Itinerary) 구조를 도입했다.
Booking 은 **Flight · Accommodation · Protocol · Transportation · Program Registration** 하위 탭으로 나뉜다.

- 카드: 성명·국가·소속/팀/직위·연락처, **Attendance(참석 상태)**, **Sponsorship(비용 지원 구분)**,
  **Principal(초청 책임자)**, 동반자 목록, `＋ Accompany 추가`
- Flight 카드: FROM/TO·Boarding Time·Passenger·Passport No·Terminal·Gate·Flight Class·Seat·Cabin Class·PNR·발권 상태
- Accommodation 카드: Check-in/out·Room Number·Room Type·Bed Type·Number of Night·Number of Guest·Breakfast·Special Meal
- Protocol 카드: 의전 등급·영접 담당/위치·의전 차량·라운지·갈라 의전 서열·기념품·포토 세션
- Itinerary: 항공·숙박·배차·프로그램을 합성한 **일자별 개인 일정**(연사 발송용과 동일)

### 2.2 데이터 정합성 검증 (신규 엔진)
엑셀 취합에서 발생하던 휴먼에러를 규칙으로 고정했다. 워크스페이스·리스크·대시보드에 노출된다.

| 규칙 | 판정 | 예시 |
|---|---|---|
| 여권 영문명 ↔ 항공 탑승자명 | 오류 | `NGUYEN MAI` vs `NGUYEN THI MAI` → 발권 정정 필요 |
| 여권 영문명 ↔ 송금 수취인명 | 오류 | 불일치 시 해외 송금 반송 |
| 여권 미수취 상태의 항공 예약 | 오류 | 이름·번호 대조 불가 |
| 체류 기간 ↔ 숙박 기간 | 경고 | 도착 당일 숙소 없음 / 조기 체크아웃 |
| 세션 일정 ↔ 항공 일정(시각 포함) | 오류 | 발표 종료 전 출국편 출발 |
| 숙박 박수 ↔ 지원 한도 | 확인 | 3박 필요 / 2박 지원 → 초과분 부담 주체 확정 |
| 동반자 객실·서류 | 경고·확인 | 객실 공유인데 투숙 인원 1명, 별도 객실 미예약, 여권 미수취 |
| 지원 구분 ↔ 실비 | 경고 | 자비 참가(Non-Sponsored)인데 주최 실비 존재 |
| 강연료 ↔ 송금 정보 | 경고 | 지급 대상인데 계좌 정보 없음 |
| 조세조약 ↔ 거주자증명서 | 확인 | 제한세율 적용 중 증명서 미수령 |
| 사증 유효기간 ↔ 입국 예정일 | 오류 | 입국 전 사증 만료 |
| 참가 형태 ↔ 예약 데이터 | 경고 | 온라인 연사에 항공·숙박 존재 |
| 참석 확정 ↔ D-30 | 확인 | 개막 30일 전까지 참석 미확정 |

### 2.3 그 외 보강
- **참석 상태(Attendance)** 를 초청 수락과 분리: 수락했더라도 비자·일정 사유로 불참할 수 있으므로 별도 관리
- **비용 지원 구분(Sponsored / 부분지원 / Non-Sponsored)**: 자비 참가자는 여행비 집계·검증에서 제외
- **Principal(초청 책임자)** 지정: 이해관계자가 많을 때 의사결정 라인을 레코드에 명시
- **프로그램 등록(Program Registration)**: 세션·만찬·리셉션 참가 상태를 개별 관리(변경 시 이력 기록)
- 대시보드에 **참석·지원 구분 현황**과 **정합성 요약** 카드 추가
- 연사 목록/Excel 내보내기에 참석 상태·지원 구분 열 추가

## 3. 검증 방법

- `npm run build` — 타입 체크(strict) 통과
- 브라우저 자동화로 **15개 화면 전체 순회 + 행사 전환(데이터 없는 행사 포함)** — 콘솔 오류 0건
- 단일 HTML 파일(`file://`)로 열어 화면 이동·상세 조회·로컬 저장 동작 확인

## 4. 남은 한계

- 데이터는 브라우저 로컬 저장이므로 **담당자 간 동기화는 되지 않는다**(서버 연동 시 해소).
- 사증·세무 기준값(심사 기간, 원천징수율 등)은 내부 참고값이며 집행 전 관계 기관 확인이 필요하다.
- 메일 발송·파일 업로드는 로그/상태만 관리하며 실제 연동은 백로그(`docs/04_리서치노트.md`) 항목이다.

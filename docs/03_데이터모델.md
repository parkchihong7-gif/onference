# 데이터 모델

정의 위치: `src/types.ts` · 시드 데이터: `src/data/seed.ts`

## 엔터티 관계

```
Conference 1 ── n Session
     │ 1
     ├── n Speaker ──┬── 1 SupportPackage (등급별 지원 템플릿)
     │               ├── 1 Passport / VisaCase
     │               ├── n Flight / Transfer, 1 HotelBooking
     │               ├── n Deliverable
     │               ├── 1 Settlement ── n Expense
     │               ├── 1 OnsiteStatus
     │               └── n Companion
     ├── n Task           (ChecklistTemplate 로부터 생성, speakerId 연결)
     ├── n Communication  (MailTemplate 기반 발송 로그)
     └── n Milestone
Member (역할: 사무국/PCO/리에종/여행사/재무/연사)
AuditLog (모든 엔터티 변경 기록)
```

## 핵심 엔터티

### Conference (행사)
`code, nameKo/nameEn, 기간, venue/city/country, timezone, host/organizer/pco, sponsors,
status(기획·준비·진행·종료), expectedAttendees, budgetTotalKRW, invitationBudgetKRW, tracks, milestones`

### Speaker (초청자) — 단일 레코드에 전 주기 데이터 집약
| 그룹 | 필드 |

| 초청 | tier, stage, **attendance(참석 상태)**, **sponsorship(Sponsored/부분지원/Non-Sponsored)**, priority, attendanceMode, recommendedBy, previousParticipation, supportPackageId, liaisonMemberId, **principalMemberId**, sessionIds |
| 일정 | firstContactAt, replyDueAt, acceptedAt, declinedAt/declineReason, agreementStatus/agreementSignedAt |

| 출입국 | passport{nameEn, numberMasked, nationality, issue/expiry, scanReceived}, visa{required, track, stage, ketaRequired/Status, ccviRequired/Number, consulate, appointmentAt, submittedAt, issuedAt, visaExpiry, leadTimeDays, guaranteeLetterRequired, memo} |

| 기타 | tags, memo, createdAt, updatedAt |

### Deliverable 13종
여권사본 · 항공선호정보 · 약력(Bio) · CV · 증명사진 · 발표초록(Abstract) · 발표자료(PPT) ·
강연동의서(Speaker Agreement) · 녹화·중계 동의서 · 개인정보 처리 동의(GDPR) ·
거주자증명서(CoR) · 해외송금 정보(W-8/은행) · 여행자보험 정보

> 온라인 연사는 여권·항공·보험 항목이 자동 제외되고, EEA 국가 연사에게만 GDPR 동의가,
> 조세조약 적용 대상에게만 거주자증명서가 생성된다.

## 파생 로직 (`src/lib/metrics.ts`)
- `computeRisks()` — 8종 리스크 자동 판정 (비자/여권/항공/숙박/의전/제출물/계약/응답)
- `validateSpeaker()` / `validateAll()` — 데이터 정합성 13종 교차 검증(오류·경고·확인)
- `buildItinerary()` — 항공·숙박·배차·프로그램을 합성한 일자별 개인 일정
- `visaLeadDays()` / `visaSlack()` — 사증 처리 필요일과 여유일(화면·엔진 공통)
- `readiness()` — 연사별 9개 실무 항목 완료율 (온라인 연사는 해당 없는 항목 제외)
- `kpis()` — 대시보드 지표 집계 (수락률, 비자·발권·제출물 진행률, 예산 약정·원천세)

## 저장
- 상태는 `localStorage('onference.state.v1')` 에 저장(내부 전용·비배포 전제).
- 모든 변경 액션은 리듀서에서 `AuditLog` 를 함께 생성한다.
- 서버 연동 시 리듀서 액션을 그대로 API 호출로 치환할 수 있도록 액션 단위를 업무 단위와 일치시켰다.

# 리서치 노트 — 국제 컨퍼런스 해외 연사 초청 시 발생하는 부가 업무

기존 골격(초기 세팅 / 초청·참가자 관리 / 진행 사항 관리 / 변경 이력)은 **국내 참가자 중심**의
행사 운영에 초점이 맞춰져 있다. 해외 연사를 초청하는 국제행사에서는 아래 업무가 추가로 발생하며,
이들이 지연되면 **연사 자체가 행사에 오지 못하는** 치명적 리스크로 이어진다.

> 아래 정리는 국제행사(MICE) 운영 실무에서 일반적으로 통용되는 절차를 기준으로 한 내부 설계 참고자료다.
> 사증·세무 규정은 국적·정책·개별 사안에 따라 달라지므로 **실제 집행 전 출입국·외국인청, 관할 재외공관,
> 세무 대리인의 최신 안내를 반드시 확인**해야 한다.

---

## A. 출입국·사증 (가장 큰 리스크)

| 항목 | 실무 내용 | 반영 위치 |
|---|---|---|
| 사증 종류 판정 | 단기방문(C-3-1) / 단기상용(C-3-4) / 단기취업(C-4). **강연료를 수령하면 수익활동으로 분류될 수 있어 체류자격 확인 필요** | `VisaCase.track`, 출입국·비자 화면 |
| 사증발급인정서(CCVI) | 주최기관이 국내에서 신청 → 발급 후 연사가 현지 공관에서 사증 수령. 심사 기간이 별도로 소요 | `ccviRequired/ccviNumber`, 리스크 역산 |
| K-ETA | 사증 면제 국적자의 전자여행허가. 면제 대상국은 정책에 따라 변동 | `ketaRequired/ketaStatus` |
| 필수 서류 | 초청장, 초청사유서, 신원보증서, 사업자등록증, 행사 프로그램, 재직증명서, 여권 사본 | 제출물·비자 체크리스트 |
| 여권 유효기간 | 입국일 기준 6개월 이상 잔여 권고. 미달 시 갱신 후 재수취 | 리스크 엔진 `여권` |
| 처리 기간 역산 | (사증 심사 + 인정서 심사 + 버퍼)를 개막일에서 역산 → 조치 마감 산출 | `computeRisks()` 비자 규칙 |
| 거절 대응 | 재신청 / 온라인 발표 전환 / 대체 연사 투입 백업 시나리오 | 온라인 전환·대체 후보 풀 |

## B. 세무·지급 (해외 송금 특유의 업무)

| 항목 | 실무 내용 | 반영 위치 |
|---|---|---|
| 원천징수 | 비거주자에게 지급하는 강연료는 국내원천소득으로 원천징수 대상 | `Settlement.withholdingRate` (기본 22% 가정) |
| 조세조약 | 조약국 거주자는 제한세율·면제 적용 가능하나, **거주자증명서와 신청서를 지급 전 수령**해야 함 | `taxTreatyApplied`, `corReceived`, 미수령 경보 |
| 해외 송금 | 수취인 영문명과 여권 영문명 불일치 시 반송. SWIFT/IBAN, 수수료 부담 주체(OUR/BEN/SHA) | `Settlement.remittance` |
| 증빙·신고 | 지급명세서·원천징수이행상황 신고, 실비 증빙(선지급/후정산 구분) | 정산 체크포인트, 정산 업무 |
| 다통화 | 항공·현지 비용의 통화 혼재 → 원화 환산 기준 필요 | `Expense.amount/currency/amountKRW` |

## C. 여행·의전

- 항공 클래스·발권 주체(주최 발권 vs 본인 구매 후 정산), 요금 보장 마감(통상 D-60), PNR·e-Ticket 관리
- 숙박 정산 방식(Master Bill vs 본인 결제), 객실 블록 마감, 루밍 리스트 제출
- 공항 픽업·샌딩: 도착 시각 연동 배차, 미팅포인트·피켓·기사 연락처, 전담 리에종 1:1 배정
- 개인 요구사항: **식이(할랄·채식·알러지), 접근성(휠체어·무대 램프), 종교, 통역, 동반자**
- 여행자보험, 24시간 비상 연락망, 결항·지연 시 대체 항공 시나리오

## D. 콘텐츠·저작권·개인정보

- 제출물 마감 체인: 약력·사진·초록(프로그램북 조판 역산) → 발표자료(기술 검수)
- 동의 관리: **녹화·중계·사진 촬영 동의**, 자료 공개 범위, 초상권
- EEA 거주 연사: GDPR 고지·동의 기록, 보유기간 경과 시 파기
- 통역: 동시/순차 배정, 자료 사전 전달, 온라인 연사의 시차·회선·사전 녹화 백업

## E. 현장·사후

- 런시트, 스피커 레디룸, 배지·기념품, 갈라디너 의전 서열, 체크인 상태 실시간 공유
- 감사 서한·만족도 설문, 세션 성과(참석·평점) 기록, 발표자료 아카이브
- 차기 행사 후보풀 이관(재초청 이력), 거절 사유 축적

## 기존 골격 대비 추가된 기능

| 기존 골격 | 이번 설계에서의 확장 |
|---|---|
| 초기 세팅(템플릿) | 등급별 **지원 패키지** + **체크리스트 템플릿(D-offset 자동 기한)** + 권한 설계 |
| 초청/참가자 관리 | 초청 **파이프라인(칸반)** + 대체 후보 풀 + 다양성 균형 점검 + 준비도 스코어 |
| 진행 사항 관리 | **비자 보드 / 발권·루밍 / 제출물 매트릭스 / 현장 상태 보드** 4축 분리 |
| 데이터 변경·히스토리 | 전 엔터티 **감사 로그** + 팔로업(회신 기한) 관리 + 리마인드 발송 로그 |
| (없음) | **리스크 D-day 역산 엔진** (8종 자동 판정) |
| (없음) | **정산·세무**(원천징수·조세조약·해외송금·다통화 실비) |
| (없음) | **의전·개인 요구사항**(식이·접근성·통역·동반자), 온라인 연사 운영 |

## 향후 확장 백로그 (이번 범위 제외)

1. **연사 포털** — 연사 본인이 여권·항공 선호·발표자료를 직접 업로드(토큰 링크, 다국어)
2. 메일 실제 발송 연동(SMTP/SendGrid) 및 수신 회신 자동 매칭
3. 파일 저장소 연동(제출물 원본 보관, 접근 로그, 보유기간 자동 파기)
4. 항공 예약 시스템(GDS)·호텔 블록 API 연동, 실시간 항공 지연 알림
5. 전자계약(Speaker Agreement e-Sign) 연동
6. 다국어 UI(EN) 및 타임존별 표시 전환
7. 서버·DB 전환(현재 로컬 스토리지) 및 역할 기반 접근 제어(RBAC) 실제 적용
8. 회계 시스템 연동(지급 결의·지급명세서 자동 생성)
9. 초청 성과 리포트 자동 생성(참석·평점·미디어 노출), 차기 후보 추천
